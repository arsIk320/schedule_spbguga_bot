# Бот напоминаний о парах

Telegram-бот поддерживает много пользователей: у каждого личное расписание и свои настройки. В 07:00 по часовому поясу пользователя бот присылает расписание на день, а перед каждой парой — предмет, время, преподавателя, кабинет и описание, как его найти. По умолчанию напоминание приходит за **15 минут**, часовой пояс — **Москва**. Можно выбрать 10 минут.

Пример сообщения:

> Через 15 минут — Математика, начало в 09:00.  
> Преподаватель: Иванов И. И.  
> Идёшь в кабинет 301.  
> Где находится: корпус А, 3 этаж, налево от лестницы.

**Проект подготовлен для запуска, но ещё не подключён к Telegram и не опубликован в вашем аккаунте.** Для этого нужны ваш токен от BotFather и несколько действий ниже. Само расписание и маршруты кабинетов вы добавляете в бота: он не определяет корпус и этаж по номеру кабинета.

## 1. Создайте бота в Telegram

1. Откройте официального [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`.
3. Укажите название, например «Мои пары».
4. Укажите свободное имя латиницей, заканчивающееся на `bot`, например `my_classes_2026_bot`.
5. Сохраните выданный токен: он выглядит как длинная строка с двоеточием. Токен позволяет управлять ботом, поэтому не публикуйте его и не добавляйте в исходный код.

Это официальный способ регистрации: [инструкция Telegram](https://core.telegram.org/bots/features#creating-a-new-bot). Дальше выберите один способ запуска: Cloudflare для работы без включённого компьютера или локальный запуск для первой проверки прямо сейчас.

## 2. Бесплатный запуск в Cloudflare через браузер

Для этого способа не требуется устанавливать программы. Нужен [аккаунт Cloudflare](https://dash.cloudflare.com/sign-up), бесплатный план Workers и файл `cloudflare-worker.mjs` из этой папки. Это готовый самостоятельный файл: копировать другие файлы проекта в редактор не нужно.

### Создайте приложение и базу

1. В панели Cloudflare откройте **Workers & Pages → Create application**. Создайте Worker через **Start with Hello World**, задайте имя `schedule-spbguga-bot` и нажмите **Deploy**.
2. Откройте созданный Worker → **Edit code**. Замените содержимое основного файла кодом из `cloudflare-worker.mjs` целиком и нажмите **Deploy**.
3. В панели откройте **D1 SQL Database** — раздел может находиться внутри **Storage & databases**. Нажмите **Create database**, задайте имя `class-reminder-bot` и создайте базу.
4. Вернитесь к Worker → **Bindings → Add binding → D1 database**. В поле имени переменной укажите **`DB`**, выберите созданную базу и сохраните.

База хранит расписание, настройки и отметки об отправленных напоминаниях между запусками. [Официальная инструкция D1](https://developers.cloudflare.com/d1/get-started/).

### Добавьте настройки

5. В Worker откройте **Settings → Variables and Secrets** и добавьте:

   | Имя | Тип | Значение |
   |---|---|---|
   | `BOT_TOKEN` | Secret | Токен, который выдал BotFather |
   | `WEBHOOK_SECRET` | Secret | Собственная случайная строка длиной от 32 символов: латинские буквы, цифры, `_`, `-` |
   | `OWNER_ID` | Text | Необязательно; обычно `0` |
   | `DEFAULT_TIMEZONE` | Text | `Europe/Moscow` |

   Сохраните `WEBHOOK_SECRET` у себя: он понадобится на следующем шаге. Это отдельный секрет, не токен BotFather. Для случайной строки можно использовать генератор паролей. Нажмите **Deploy**, если панель предлагает применить изменения.

6. Откройте **Settings → Triggers → Cron Triggers**, добавьте расписание **каждую минуту**:

   ```text
   * * * * *
   ```

   Сохраните. Первый запуск после добавления или изменения триггера может появиться через несколько минут; Cloudflare указывает срок распространения настройки до 15 минут. [Документация Cron Triggers](https://developers.cloudflare.com/workers/configuration/cron-triggers/).

### Подключите Telegram

7. Найдите адрес Worker вида `https://schedule-spbguga-bot.ВАШ-ПОДДОМЕН.workers.dev`. Откройте его, дописав **`/setup`** в конце.
8. Введите `WEBHOOK_SECRET`, который сохранили на шаге 5, и нажмите **«Подключить»**. Страница создаст нужные таблицы в базе и подключит Telegram к этому Worker. Через форму также можно проверить состояние подключения.
9. Откройте **своего нового бота** в Telegram и отправьте `/start`. Новый пользователь получает копию шаблона группы `26-01`; для английского выберите свою подгруппу командой `/english 1`, `/english 2` или `/english 3`.
10. Проверьте `/today`, `/table` и `/test`. Любой пользователь может затем заменить шаблон своим импортом через `/import`; его расписание хранится отдельно.

`OWNER_ID` больше не ограничивает обычные команды и может оставаться равным `0`. Он нужен только для необязательной миграции расписания из старой однопользовательской версии; для безопасности бот принимает команды только в личных чатах.

Чтобы проверить напоминания, добавьте временную пару, которая начнётся через 17–20 минут, и дождитесь сообщения. После проверки замените расписание своим. `/test` проверяет отправку сообщения, но сам по себе не проверяет работу облачного таймера.

## 3. Добавьте своё расписание

Отправьте боту `/import` без текста — он покажет актуальный пример формата. Можно отправить расписание сообщением, начиная с `/import`, или вставить только строки расписания.

Одна строка — одна пара. Поля разделяются вертикальной чертой `|`:

```text
День | Время | Предмет | Преподаватель | Кабинет | Где находится
```

Пример сообщения — **без строки с названиями колонок**:

```text
/import
Пн | 09:00 | Математика | Иванов И. И. | 301 | Корпус А, 3 этаж, налево от лестницы
Пн | 10:40 | Физика | Петрова А. В. | 204 | Корпус Б, 2 этаж, напротив лифта
Вт | 09:00 | История | Сидоров П. Н. | 115 | Главный корпус, 1 этаж, правое крыло
```

**Каждый импорт полностью заменяет прежнее расписание.** Сначала соберите все нужные строки в одном сообщении или одном файле. Если в строках есть ошибка, бот объяснит её, а прежнее расписание сохранится.

- Расписание повторяется каждую неделю. Время указывайте в формате `09:00`, в выбранном часовом поясе.
- Допускается до 100 пар, но сообщение Telegram также ограничено по длине: до 4096 символов. Для длинного расписания отправьте боту один файл **`.txt` в кодировке UTF-8, размером до 32 КБ**, с теми же строками. Подойдёт обычный Блокнот: «Сохранить как» → UTF-8. Готовый образец — `examples/schedule.txt`.
- Не отправляйте части расписания отдельными импортами: каждое сообщение или файл заменит предыдущие данные.
- Не используйте `|` внутри названия предмета, имени преподавателя или описания кабинета: это разделитель полей.
- Фото, PDF и Excel автоматически не распознаются. Нужны текстовые строки в сообщении или `.txt`.
- Во время каникул включите `/pause`, перед возвращением к занятиям — `/resume`. Календарь праздников и учебного семестра не загружен.

После импорта отправьте `/week` и проверьте время, кабинеты и преподавателей.

### Чётные и нечётные недели

При необходимости добавьте седьмую колонку: `чёт`, `нечёт` или `каждую` для каждой недели. Без седьмой колонки пара проходит каждую неделю.

```text
Пн | 09:00 | Математика | Иванов И. И. | 301 | Корпус А, 3 этаж | чёт
Пн | 09:00 | Физика | Петрова А. В. | 204 | Корпус Б, 2 этаж | нечёт
```

Чётность определяется **номером календарной недели ISO**, а не количеством недель от начала семестра. Если вуз считает недели по своему календарю, сначала сопоставьте его с этой нумерацией.

Для английского добавьте восьмую колонку с номером группы `1`, `2` или `3`:

```text
Пн | 10:45 | Иностранный язык (английский) | Мухтабарова О.И. | к7 | Корпус уточнить | чёт | 1
Пн | 10:45 | Иностранный язык (английский) | Антонова Е.Е. | к7 | Корпус уточнить | чёт | 2
Пн | 10:45 | Иностранный язык (английский) | Яковлева К.М. | к7 | Корпус уточнить | чёт | 3
```

В шаблоне группы `26-01` эти три варианта уже распознаны. Выбери свой вариант командой `/english 1`, `/english 2` или `/english 3`; `/english all` показывает все три.

Шаблон собран по присланной фотографии. Если на исходном листе есть более точный заголовок групп или исправления по аудиториям, пришли полный верх листа и обнови шаблон перед массовым запуском.

### Таблица кабинетов и маршруты

Команда `/table` выводит распознанные сочетания «кабинет — преподаватель — предмет». Чтобы добавить путь к кабинету, открой адрес своего Worker и допиши `/rooms`, например `https://имя-worker.workers.dev/rooms`. Введи `WEBHOOK_SECRET`, номер кабинета и текст маршрута, затем нажми «Сохранить маршрут». Сохранённая подсказка автоматически появляется в утреннем сообщении, `/today` и напоминании перед парой.

## Команды в Telegram

| Команда | Что делает |
|---|---|
| `/start` | Начать работу и показать подсказку |
| `/help` | Помощь и формат расписания |
| `/id` | Узнать свой Telegram ID |
| `/import` | Показать пример импорта; с текстом — заменить расписание |
| `/today` | Пары на сегодня |
| `/tomorrow` | Пары на завтра |
| `/week` | Расписание недели |
| `/table` | Таблица кабинетов, преподавателей и предметов |
| `/english 1` | Выбрать одну из трёх групп английского |
| `/group` | Восстановить распознанный шаблон группы 26-01 |
| `/settings` | Посмотреть настройки |
| `/remind 15` | Напоминать за 15 минут |
| `/remind 10` | Напоминать за 10 минут |
| `/timezone Europe/Moscow` | Установить часовой пояс |
| `/pause` | Приостановить напоминания |
| `/resume` | Включить напоминания |
| `/test` | Отправить тестовое сообщение |
| `/clear confirm` | Удалить всё расписание |

Для другого города задайте его часовой пояс, например `/timezone Asia/Yekaterinburg`. Это настройка времени занятий, а не языка Telegram. Часовой пояс облачного таймера вручную менять не нужно: бот сам сопоставляет расписание со временем запуска.

## Запуск на своём компьютере прямо сейчас

Понадобится [Node.js 24 или новее](https://nodejs.org/). Отдельно устанавливать пакеты для локального запуска не нужно.

1. Откройте PowerShell в папке `class-reminder-bot`.
2. Создайте файл настроек из примера:

   ```powershell
   Copy-Item .env.example .env
   ```

3. Откройте `.env` в текстовом редакторе, вставьте токен в `BOT_TOKEN`, оставьте `OWNER_ID=0` и сохраните.
4. Запустите:

   ```powershell
   node --env-file=.env scripts/local.mjs
   ```

5. Отправьте `/start`, `/test` и добавьте расписание. Каждый пользователь работает со своим отдельным расписанием.

Данные сохраняются в `data/bot.sqlite`. Не удаляйте этот файл, если хотите сохранить расписание. Компьютер должен быть включён, подключён к интернету, не находиться в спящем режиме, а программа должна продолжать работать. После выключения компьютера напоминания не отправляются.

Если этот же бот уже подключён к Cloudflare через webhook, программа сообщит об этом и откажется запускаться. Для сознательного перехода с облака на локальный запуск:

```powershell
node --env-file=.env scripts/local.mjs --remove-webhook
```

Перед переходом также отключите Cron Trigger в Cloudflare: удаление webhook прекращает получение команд облаком, но не останавливает облачные напоминания. Локальная и облачная базы отдельные — перенесите расписание импортом. Для возвращения в облако остановите локальную программу, включите Cron Trigger и снова подключите бота через `/setup`.

## Другой способ: Cloudflare через командную строку

Этот раздел заменяет создание Worker через браузер. Используйте либо этот способ, либо основной; не создавайте два независимых экземпляра для одного бота.

1. Установите Node.js 24 или новее. Откройте PowerShell в папке проекта и выполните:

   ```powershell
   npx wrangler@4 login
   npx wrangler@4 d1 create class-reminder-bot
   ```

2. Скопируйте настоящий UUID базы `class-reminder-bot` в `wrangler.toml` вместо `REPLACE_WITH_D1_DATABASE_ID`. Его можно посмотреть в Cloudflare в **D1 → class-reminder-bot → Database ID** или получить командой `npx wrangler@4 d1 list`. Одного имени базы недостаточно для Workers Builds: `database_id` должен быть реальным UUID. Имя binding должно остаться `DB`, а имя Worker — `schedule-spbguga-bot`.
3. Выполните публикацию и добавьте секреты. Каждая команда `secret put` запросит значение отдельно:

   ```powershell
   npx wrangler@4 deploy
   npx wrangler@4 secret put BOT_TOKEN
   npx wrangler@4 secret put WEBHOOK_SECRET
   ```

4. Откройте выданный HTTPS адрес с `/setup`, введите `WEBHOOK_SECRET` и нажмите «Подключить». Таблицы создаются на этом шаге, отдельный импорт SQL не нужен.
5. Отправьте `/start`, `/test` и импортируйте расписание. Ежеминутный Cron Trigger уже указан в `wrangler.toml`.

При таком способе дальше меняйте настройки в `wrangler.toml`: очередная публикация может заменить сделанные вручную изменения в панели. Токены хранятся в Secrets. `.env` применяется локально и сам по себе не загружает секреты в Cloudflare.

Нужны платёжный аккаунт, постоянное хранилище и адаптация проекта: файл Workers нельзя просто вставить в Yandex. Сверх квот ресурсы платные. Для Yandex стартовый грант — отдельная временная акция, его не следует путать с ежемесячными бесплатными квотами. Из перечисленных вариантов готовый проект без переделки публикуется в Cloudflare.

Cloudflare сообщает об ограничениях прямого доступа из российских сетей: иногда может не открываться панель или сайт Worker. Это не подтверждение сбоя серверного обмена между Telegram и Cloudflare; состояние webhook проверяйте через `/setup`. [Официальное сообщение Cloudflare](https://developers.cloudflare.com/support/troubleshooting/general-troubleshooting/service-disruption/).

## Если сообщение не приходит

1. Убедитесь, что вы открыли диалог с ботом, отправили `/start` и не отключили уведомления Telegram.
2. Отправьте `/test`. Если ответа нет, проверьте токен, опубликованные изменения и состояние подключения на `/setup`.
3. Если тест работает, проверьте `/settings`, `/today`: уведомления должны быть включены, часовой пояс и время занятий — верными.
4. В Cloudflare проверьте Cron Trigger `* * * * *` и журнал запусков. После первой настройки дайте триггеру до 15 минут на активацию.
5. При локальном запуске проверьте, что окно программы открыто и компьютер не уснул.

Проверка расписания выполняется раз в минуту. Бот хранит отметки об отправке и обычно не повторяет одно напоминание. Если проверка задержалась, он может догнать напоминание до начала пары; после начала пары старое уведомление не отправляет. Сбой сети в момент отправки в редких случаях может привести к повтору. Точная доставка до секунды не гарантируется.

## Файлы и проверка проекта

- `cloudflare-worker.mjs` — готовый файл для вставки в панель Cloudflare.
- `src/worker.mjs` — команды бота, webhook и отправка напоминаний.
- `src/schedule.mjs` — проверка и обработка расписания.
- `scripts/local.mjs` — локальный запуск с SQLite.
- `wrangler.toml` — настройки публикации через командную строку.
- `.env.example` — пример локальных настроек.

Из папки проекта:

```powershell
node --test
node scripts/build.mjs
```

Вторая команда собирает `cloudflare-worker.mjs` из исходников. После изменения исходников пересоберите этот файл перед копированием в панель.

Telegram подключается через [setWebhook](https://core.telegram.org/bots/api#setwebhook) с проверкой секретного заголовка. Одновременное получение команд через webhook и локальный опрос Telegram не поддерживается.
